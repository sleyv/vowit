### 📖 Описание

**vowit** — это мощный, легковесный фоновый демон для сред рабочего стола Linux (таких как Hyprland, Sway, KDE, GNOME), который добавляет функцию мгновенного голосового набора (push-to-talk) в ваш рабочий процесс.

Он захватывает звук напрямую с вашего микрофона или системного вывода, автоматически обрезает тишину с помощью модели ONNX Voice Activity Detection (VAD) и транскрибирует речь с помощью молниеносного API Groq Whisper. Распознанный текст мгновенно копируется в буфер обмена.

Благодаря встроенной возможности исправления грамматики через LLM, десктопным уведомлениям и переключению через CLI с нулевой задержкой, он выступает в роли идеального голосового помощника для продвинутых пользователей.

### ✨ Ключевые особенности

- **🚀 Мгновенное переключение**: Разработано специально для привязки к глобальным горячим клавишам. Отправка сигналов демону занимает миллисекунды и не требует загрузки виртуального окружения Python.
- **🎙️ Два режима захвата**: Записывайте звук с микрофона для диктовки или захватывайте внутренний системный звук (например, YouTube, Discord) для транскрибации.
- **🔇 Умная обрезка тишины**: Использует легкую нейросеть Silero VAD (ONNX) и TrueRMS лимитер для фильтрации фонового шума и локальной обрезки тишины перед отправкой данных, экономя трафик и повышая точность.
- **✨ Исправление грамматики (Опционально)**: Автоматически прогоняйте транскрибированный текст через Groq LLM для аккуратного исправления грамматики, фонетических ошибок и расстановки абзацев.
- **🔊 Богатый саунд-дизайн**: Использует нативные звуки `freedesktop` для звуковой обратной связи в 4 разных состояниях: Старт, Стоп/Обработка, Успех и Ошибка.
- **⏱️ Автоматический таймаут**: Встроенный 10-минутный лимит безопасности автоматически останавливает запись и обрабатывает звук, если вы забыли ее выключить.

### 🛠️ Требования

Перед установкой убедитесь, что в вашей системе Linux установлены следующие зависимости через ваш пакетный менеджер (`apt`, `pacman`, `dnf`):
- `ffmpeg` (для захвата аудио и конвертации форматов)
- `wl-clipboard` (а именно `wl-copy` для работы с буфером обмена в Wayland. Используйте `xclip` в X11 и измените скрипт соответствующим образом)
- `libnotify-bin` или `mako`/`dunst` (для `notify-send`)
- `pulseaudio-utils` (для воспроизведения звука через `paplay`)

### 🚀 Быстрый старт

#### 1. Клонирование и подготовка
```bash
git clone https://github.com/yourusername/vowit.git
cd vowit
```

#### 2. Установка зависимостей Python
Настоятельно рекомендуется использовать виртуальное окружение.
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

#### 3. Настройка переменных окружения
Создайте файл `.env` из предоставленного шаблона и вставьте ваш API ключ Groq:
```bash
cp .env.example .env
# Отредактируйте .env и вставьте ваш GROQ_API_KEY
```

### ⚙️ Использование и шорткаты

Приложение разделено на **фоновый демон** и **CLI инструмент для переключения**.

#### 1. Запуск демона (При старте системы)
Запустите демона, используя исполняемый файл Python из вашего виртуального окружения. Он запустится в фоновом режиме и будет ждать сигналов.
```bash
/путь/к/vowit/.venv/bin/python /путь/к/vowit/main.py &
```

#### 2. Настройка горячих клавиш
В конфигурационном файле вашего оконного менеджера (например, `hyprland.conf`, `sway/config`), привяжите следующие команды к желаемым клавишам. Для этого шага можно использовать глобальный системный Python для нулевой задержки.

**🎤 Переключение диктовки (Микрофон):**
```bash
python3 /путь/к/vowit/main.py toggle
```

**🔊 Переключение записи системного звука:**
```bash
python3 /путь/к/vowit/main.py toggle_sys
```

**✨ Переключение диктовки + Исправление грамматики через LLM:**
```bash
python3 /путь/к/vowit/main.py toggle fixon
```

Нажмите горячую клавишу один раз, чтобы начать запись (вы услышите звук входа). Нажмите её снова, чтобы остановить запись и обработать аудио. Распознанный текст автоматически появится в вашем буфере обмена!
