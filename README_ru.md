### 📖 Описание

**vowit** — это мощный, легковесный фоновый демон для сред рабочего стола Linux, который добавляет функцию мгновенного голосового набора (push-to-talk) в ваш рабочий процесс.

- 🎙️ **Два режима**: Запись микрофона или системного звука.
- 🔇 **Умная обрезка**: Silero VAD (ONNX) фильтрует шум и обрезает тишину.
- ⚡ **Нулевая задержка**: Мгновенное переключение CLI, идеально для шорткатов.
- ✨ **Исправления LLM**: Опциональное исправление грамматики через Groq LLM.
- 🔊 **Звуковой отклик**: Нативные звуки уведомлений `freedesktop`.

---

### 🛠️ Требования

Убедитесь, что в вашей системе установлены следующие зависимости:
- `ffmpeg`
- `wl-clipboard` (используйте `xclip` для X11 и измените скрипт)
- `libnotify-bin` или `mako`/`dunst`
- `pulseaudio-utils`

### 🚀 Быстрый старт

#### 1. Клонирование и подготовка
```bash
git clone https://github.com/sleyv/vowit.git ~/vowit
cd ~/vowit
```

#### 2. Установка зависимостей Python
Настоятельно рекомендуется использовать виртуальное окружение.
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

#### 3. Настройка переменных окружения
Вам потребуется **Groq API ключ**.
1. Сгенерируйте API-ключ в [Groq Cloud Console](https://console.groq.com/keys).
2. Создайте файл `.env` из шаблона:
   ```bash
   cp .env.example .env
   ```
3. Отредактируйте файл `.env` и вставьте ваш `GROQ_API_KEY`. Также там есть другие интересные настройки, которые вы можете изучить и изменить, такие как язык интерфейса и модель Whisper!

### ⚙️ Использование и шорткаты

Приложение состоит из **фонового демона** и **CLI переключателя**.

#### 1. Запуск демона
Запустите демона, используя Python из вашего виртуального окружения. **Вам необходимо настроить автозапуск демона при старте системы** (например, с помощью `exec-once` в конфигурации оконного менеджера или через systemd user service).
```bash
~/vowit/.venv/bin/python ~/vowit/main.py &
```

#### 2. Настройка горячих клавиш
В конфигурации вашего оконного менеджера (например, `hyprland.conf`, `sway/config`), привяжите следующие команды к горячим клавишам. **Используйте обычный системный `python3`** для этих команд, чтобы обеспечить нулевую задержку!

**🎤 Переключение диктовки (Микрофон):**
```bash
python3 ~/vowit/main.py toggle
```

**🔊 Переключение записи системного звука:**
```bash
python3 ~/vowit/main.py toggle_sys
```

**✨ Переключение диктовки + Исправление грамматики через LLM:**
```bash
python3 ~/vowit/main.py toggle fixon
```

*(Вы также можете добавить `fixon` к команде `toggle_sys`)*

Нажмите горячую клавишу для начала записи (прозвучит звук). Нажмите снова для остановки и обработки. Текст автоматически появится в буфере обмена!
